# Zulangue

[English](README.md) | [ไทย](README.th.md) | **မြန်မာ** | [日本語](README.ja.md) | [Français](README.fr.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [简体中文](README.zh-Hans.md)

Zulangue သည် macOS အတွက် native အသံမှတ်စုအက်ပ်ဖြစ်ပြီး အသံဖမ်းခြင်း၊
စာသားပြောင်းခြင်းနှင့် အကြောင်းအရာစုစည်းခြင်းတို့ကို ကူညီပေးကာ
ဘာသာစကားစုံ စကားဝိုင်းများကို လိုက်ပြသည့် မျှောစာတန်း (floating subtitles) ပါရှိသည်။

## ဒေါင်းလုဒ်

[Zulangue နောက်ဆုံးဗားရှင်းကို ဒေါင်းလုဒ်လုပ်ရန်](https://github.com/4seas-community/zulangue/releases/latest)

Apple Silicon နှင့် Intel Mac နှစ်မျိုးလုံးကို ထောက်ပံ့သည်။ macOS 15.5 သို့မဟုတ် ပိုမြင့်သောဗားရှင်း လိုအပ်သည်။

ထည့်သွင်းဖိုင်သည် Apple ၏ notarization မရသေးပါ။ ပထမဆုံးဖွင့်ချိန်တွင် macOS က
ပိတ်ဆို့ပါက Finder ထဲတွင် Control ခလုတ်နှိပ်ထားပြီး Zulangue ကိုနှိပ်၍ "Open" ကိုရွေးပါ၊
သို့မဟုတ် System Settings → Privacy & Security သို့သွား၍ ခွင့်ပြုနိုင်သည်။

## အဓိကလုပ်ဆောင်ချက်များ

- အသံဖမ်းခြင်း သို့မဟုတ် အသံဖိုင်ထည့်သွင်းပြီး Soniox ဖြင့် စာသားပြောင်းခြင်း
- ရွှေ့နိုင်၊ အရွယ်အစားချိန်နိုင်သော မျှောဝင်းဒိုးတွင် ဘာသာစကားစုံ တိုက်ရိုက်စာတန်းများ ပြသခြင်း
- အသံဖမ်းချက်၊ စာသားနှင့် မှတ်စုများကို Notebook ထဲတွင် စုစည်းခြင်း
- အကြောင်းအရာများကို တည်းဖြတ်၊ ရှာဖွေ၊ ထုတ်ယူခြင်း
- အက်ပ်တွင်း အပ်ဒိတ်အသိပေးချက်ဖြင့် ဗားရှင်းအသစ်များ ရယူခြင်း

## ကိုယ်ရေးလုံခြုံမှု

အသံ၊ စာသားနှင့် မှတ်စုများကို မူရင်းသတ်မှတ်ချက်အရ သင့်စက်ထဲတွင်သာ သိမ်းဆည်းသည်။
အဝေးမှ စာသားပြောင်းခြင်းကို သင်ကိုယ်တိုင် အသုံးပြုမှသာ သက်ဆိုင်ရာအကြောင်းအရာကို
ဝန်ဆောင်မှုပေးသူထံ ပို့သည်။ API အထောက်အထားများကို စက်တွင်းတွင်သာ သိမ်းဆည်းပြီး
ကုဒ်သိုလှောင်ရုံထဲသို့ မတင်ပါ။
