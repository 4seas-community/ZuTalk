# Zulangue

[English](README.md) | [ไทย](README.th.md) | **日本語** | [Français](README.fr.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [简体中文](README.zh-Hans.md)

Zulangue は macOS ネイティブのボイスノートアプリです。録音・文字起こし・
コンテンツの整理を支援し、フローティング字幕で多言語の会話を追いかけられます。

## ダウンロード

[最新版の Zulangue をダウンロード](https://github.com/4seas-community/zulangue/releases/latest)

Apple Silicon と Intel の両方の Mac に対応。macOS 15.5 以降が必要です。

現在のインストーラは Apple の公証(ノータリゼーション)を受けていません。
初回起動時に macOS にブロックされた場合は、Finder で Control キーを押しながら
Zulangue をクリックして「開く」を選ぶか、「システム設定 → プライバシーと
セキュリティ」から許可してください。

## 主な機能

- 録音または音声の読み込みを行い、Soniox で文字起こし
- 移動・サイズ変更できるフローティングウインドウに多言語のライブ字幕を表示
- 録音・文字起こし・メモを Notebook にまとめて整理
- コンテンツの編集・検索・書き出し
- アプリ内のアップデート通知で新バージョンを入手

## プライバシー

音声・文字起こし・メモは、デフォルトではお使いの Mac にのみ保存されます。
リモート文字起こしを自分で使用したときに限り、該当するコンテンツが
サービス提供者に送信されます。API 認証情報はローカルに保存され、
リポジトリにコミットされることはありません。
