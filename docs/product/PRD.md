# Zulangue 产品说明

Zulangue 是面向多语言沟通与会议的 macOS 现场工具。它让每一场多语言交流，
从现场理解、会中笔记到会后整理，都在同一个地方完成。

数据默认保存在这台 Mac。远端转录由用户在具体会议中开启。

## 核心流程

1. 创建或选择 Notebook。
2. 在 Notebook 的实时转录、异步转录、个人笔记或资源标签间切换。
3. 每次录音创建一个 Session，并建立对应资源文件。
4. 实时文本、异步处理结果和个人笔记分别进入对应视图。
5. 在各标签中按时间顺序回看文件，打开单次录音，或导出结果。

用户也可以导入已有音频并单独发起异步转录。

## 信息架构

- 首页是 Notebook 书架，只承担选择和新建，不展示某个 Notebook 的录音明细。
- Notebook 是项目或沟通场景的长期容器。
- 每个 Notebook 固定包含四个标签：实时转录、异步转录、个人笔记、资源。
- Session 是一次录音或导入，不是 Notebook 标签。
- 每个 Session 都有稳定的资源集合；资源共享同一个 `session_id`，但内容与写入
  权限彼此独立。
- 实时转录和异步转录按 Session 线性排列对应文件。

四个固定标签分别承担：

- 实时转录：录音中的实时文本、语言与说话人信息。
- 异步转录：异步处理状态、最终文本及失败后的恢复动作。
- 个人笔记：可滚动的线性“时间笔记”流。每个时间点形成一份完整笔记，必须保留
  创建时间，并可选关联 Session。笔记可以无标题；命名或重命名表示给该时间点的
  整份笔记命名，不是给其中某个段落或资源文件命名。后台任务不能改写笔记正文。
- 资源：统一显示 Session 对应的音频、实时转录、异步转录和笔记文件，以及每个
  文件的状态。

资源状态至少包括未生成、生成中、可用、失败和缺失。资源标签只负责查看、打开和
恢复文件，不承载转录正文或笔记编辑。音频播放、导出和任务错误属于具体 Session。
首页不重复提供 Notebook 内部操作。

个人笔记的标题、创建时间、Session 关系和正文是不同字段。重命名只修改标题，
不能改变创建时间、Session 关系或正文。无标题笔记以时间作为主要识别信息。

## 数据边界

- Notebook、录音、转录和笔记以本机数据为准。
- 麦克风音频只在用户开始对应录音后发送给已配置的转录服务。
- 导入音频只在用户明确发起转录后发送。
- Context Pack 在预览并确认后才会附加到服务请求。
- 凭据只用于建立服务连接，不自动授权任何音频或文本传输。
- 远程服务不可用时，本地录音仍应继续并被可靠保存。

## 文档写入

用户编辑和确定性的转录投影是 Notebook 文档的写入来源。后台处理不能在没有
明确产品交互的情况下改写用户笔记。

## macOS 范围

当前仓库只提供 macOS 应用。界面和系统集成位于 Swift，业务规则、持久化、
转录协议、加密和导出位于 Rust。
