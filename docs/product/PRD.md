# Zulangue 产品说明

Zulangue 是面向多语言沟通与会议的 macOS 现场工具。它让每一场多语言交流，
从现场理解、会中笔记到会后整理，都在同一个地方完成。

数据默认保存在这台 Mac。远端转录由用户在具体会议中开启。

## 核心流程

1. 创建或选择 Notebook。
2. 选择本次录音使用的语言。
3. 开始录音并查看实时文本。
4. 停止录音，保留本地录音和已收到的转录结果。
5. 编辑笔记，重新打开 Notebook，或导出结果。

用户也可以导入已有音频并单独发起异步转录。

## 数据边界

- Notebook、录音、转录和笔记以本机数据为准。
- 麦克风音频只在用户开始对应录音后发送给已配置的转录服务。
- 导入音频只在用户明确发起转录后发送。
- Context Pack 在预览并确认后才会附加到服务请求。
- 凭据只用于建立服务连接，不自动授权任何音频或文本传输。
- 远程服务不可用时，本地录音仍应继续并被可靠保存。

## 文档写入

用户编辑和确定性的转录投影是 Notebook 文档的写入来源。后台处理不能在没有
明确产品交互的情况下改写用户笔记。

## macOS 范围

当前仓库只提供 macOS 应用。界面和系统集成位于 Swift，业务规则、持久化、
转录协议、加密和导出位于 Rust。
