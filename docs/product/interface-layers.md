# 界面分层

定案 2026-11-13，随 0.8.2 落地。0.8.1 盘点下来，按「开始录音」之前页面上有
14 个控件，录音中有 19 个，字幕正不正常在六处各说一遍，同一件事有八个名字。
这一页写的是之后每一处界面都要守的规矩：功能不删，分三层摆。

## 给谁用

- **四五十岁的上班族。** 打开、录、停、把字贴走。不该需要认识任何一个新词。
- **二十多岁的人和运营。** 愿意多学一点：多语、给观众看字幕、交到城的档案馆。
  工具都在，多点一下。

## 三层

| 层 | 谁看到 | 有什么 |
| --- | --- | --- |
| 第一层 | 所有人，一直在 | 开始录音；文字和译文；标记、暂停、停止；复制全文、导出 |
| 第二层 | 点「更改」或「⋯」 | 说的语言、另外译成；声音来源；放进主题；字幕窗；并排对照；精修；分享链接；给观众看字幕 |
| 第三层 | 打开「我在主持活动」 | 录音条上的「给观众看字幕」按钮；归到城里的哪场活动 |
| 不显示 | 只在「设置 › 高级」 | 供应商和模型名；延迟的秒数；翻译连接数；「本次录音配置已冻结」 |

不设「简单版 / 完整版」的总开关。

### 「我在主持活动」

一个按场合说的开关（`HostMode`，`App/HostMode.swift`），在首页开始录音的
选项里。人还没碰过它的时候，登录了城的身份就算开着，没登录就算关着。

**正在用的东西不因为开关关着而消失。** 一场直播正在进行，录音条上那个按钮
照样在；一场录音已经归了活动，那个去向照样在。开关只决定入口摆不摆出来。

## 一屏一个主要动作

- **首页**：一个「开始录音」。下面一句话写着这一场会怎么录（说什么语言、
  译成什么、声音从哪来），旁边一个「更改」。再下面是录过的东西，按日期排。
  「开始录音」不再是单独的一页。
- **录音中**：文字占满。录音条上四样：标记、暂停、停止、⋯。
- **停止以后**：落在这场录音的页面上，顶上一张卡：录好了、多长、接下来能做
  什么。第一个按钮是「复制全文」，复制的是眼前这一版。正在写这场录音笔记的人
  不被带走，只出一句提示；卡在他回到文字稿时还在。

## 状态只说一处、一句

录音中文字正不正常，只在录音条计时旁边说一句；要人动手的时候，顶栏下面那一条
横幅给出原因和唯一的动作。别处不再重复。

先说录音有没有受影响，再说文字怎么了。不报秒数。

| 情况 | 那一句（简体 / English） |
| --- | --- |
| 一切正常 | 正在录音 / Recording |
| 这一场只录音 | 正在录音 · 只录音 / Recording · audio only |
| 文字还在接通 | 正在录音 · 正在接通文字 / Recording · connecting text |
| 文字落后 | 正在录音 · 文字慢了一点 / Recording · text is a little behind |
| 一部分语言停了 | 正在录音 · 部分文字停了 / Recording · some text stopped |
| 文字全停了 | 正在录音 · 文字停了 / Recording · text stopped |
| 没联网 | 正在录音 · 没联网，暂时出不了字 / Recording · offline, no text for now |
| 暂停、保存中 | 沿用原来的说法 |

## 主题是可选的

人只需要认识「录音」。录音默认按日期排；主题是给一个系列归类用的文件夹，
建了第一个，侧栏才出现「主题」。存储不变：没放进主题的录音仍在那个系统主题
里，界面上不再提它，也不再出现「未归入主题」这几个字——没放的录音就是录音。

一场录音的页面上不放「下一场录音」的默认值。默认值只在两处：首页的「更改」，
和主题自己的选项。

## 设置三节

- **账号**：登录 Zu 的身份（现在就是城的扫码登录）；转录和翻译靠什么在跑
  （邀请码，或自己的密钥）；我的设备；城的档案馆。
- **通用**：界面语言、外观、更新、快捷键。
- **高级**：自己的 Soniox 密钥、整理用的模型密钥、正在分享的链接、备份与恢复、
  诊断信息。大多数人用不到。

登录以后转录由谁出钱，要等身份体系和服务端定下来。在那之前不登录也能用，
邀请码和自己的密钥照旧。

## 用词

一件事一个名字。下面是界面上唯一允许的说法；左栏的旧说法出现在界面上算缺陷。

| 旧说法 | 简体 | English |
| --- | --- | --- |
| 转录稿、转录、转写稿 | 文字稿 | transcript |
| 精修转录、精修版、音频转录、转录这段音频、录音后处理、停止后处理 | 精修（动作）· 精修稿（结果） | refine · refined transcript |
| 实时版、实时转录（指那一版稿子） | 边录边出的那一版 | the live version |
| 实时字幕（指开关） | 边录边出字 | live text |
| 实时字幕、悬浮字幕（指那个窗口） | 字幕窗 | caption window |
| 共享字幕、直播（指给会场的人看） | 给观众看字幕 | show captions to the audience |
| 现场说 / 只看字幕 | 说的语言 / 另外译成 | spoken languages / also translate into |
| 系统声音 | 电脑里的声音 | sound from this Mac |
| 全部录音 | 录音 | recordings |
| 未归入主题、首页快速录音 | （不出现） | — |
| 废纸篓 | 回收站 | trash |
| 共享（指发给别人看） | 分享 | share |
| 共享（指一起改主题笔记） | 协作 | collaborate |
| 主题设置 | 主题选项 | topic options |
| 密钥（不带名字） | Soniox 密钥、DeepSeek 密钥 | Soniox key, DeepSeek key |

「活动」只指城里的活动。字幕窗的两种排法叫「最新一句」和「对照」（那个切换
只有 144 pt 宽，各语言都用短词）。

供应商名（Soniox、DeepSeek）只出现在三种地方：「设置 › 高级」；首次使用里选
「用自己的密钥」的那一步；以及告诉人音频会发到哪里的那几句——那是告知，不能
为了用词干净把名字去掉。录音中的状态、提示和报错只说文字怎么了。

## 这一版没做的

- 「整理成纪要」：新功能，没定做不做。
- 登录以后转录由城提供：要服务端认身份。
- 我的设备、协作跟着身份走：要改同步那一层。
- 说话人的显示没有动。
- 字幕窗悬停时的那一排控件没有动，停止在那里还有一个入口。
- 没人引用的旧字符串没有清。
