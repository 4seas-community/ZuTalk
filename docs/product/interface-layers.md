# 界面分层

定案 2026-11-13，随 0.8.2 落地。0.8.1 盘点下来，按「开始录音」之前页面上有
14 个控件，录音中有 19 个，字幕正不正常在六处各说一遍，同一件事有八个名字。
这一页写的是之后每一处界面都要守的规矩：功能不删，分三层摆。

## 给谁用

- **四五十岁的上班族。** 打开、录、停、把字贴走。不该需要认识任何一个新词。
- **二十多岁的人和运营。** 愿意多学一点：多语、给观众看字幕、交到城的档案馆。
  工具都在，多点一下。

## 三层

| 层 | 谁看到 | 有什么 |
| --- | --- | --- |
| 第一层 | 所有人，一直在 | 开始录音；语言、声音、主题（就在开始按钮下面，原地改）；文字和译文；标记、暂停、停止；复制、导出 |
| 第二层 | 点「⋯」或一颗胶囊的菜单 | 字幕窗；并排对照；精修；分享链接；给观众看字幕；改名、放进主题、详情、删除；登录了城的人，录好的录音「交到活动」 |
| 第三层 | 打开「主持活动」 | 录音条上的「给观众看字幕」按钮；归到城里的哪场活动、这一场交不交音频；录好的录音页面上的「交到活动」 |
| 不显示 | 只在「设置 › 高级」 | 供应商和模型名；延迟的秒数；翻译连接数；「本次录音配置已冻结」 |

不设「简单版 / 完整版」的总开关。

**出字不是一个选择**（0.8.4）。负责人指着首页那颗「出字」胶囊和它的 ⓘ 说：
「默认录音就是出字，不需要有这个可配置的。」有东西能出字——邀请码，或自己的
密钥——就出字；哪一层都没有这个开关。只录音是「没有邀请码也没有密钥」的结果，
在「设置 › 账号」里，不是每场录音前选的。开始按钮旁边只在出不了字的时候多一样
东西：还没设置，是一颗去设置的胶囊「出字」；没联网，是一个状态（图标加一个
词）。出字时音频会发给 Soniox 这条告知，在开始按钮的提示里，和「设置 › 账号」
「出字」小标题旁的 ⓘ 里。用邀请码而这台 Mac 没联网时，这一场照常开始，只录音，
出一句提示。

### 「我在主持活动」

一个按场合说的开关（`HostMode`，`App/HostMode.swift`），在首页开始录音的
选项里。人还没碰过它的时候，登录了城的身份就算开着，没登录就算关着。

**正在用的东西不因为开关关着而消失。** 一场直播正在进行，录音条上那个按钮
照样在；一场录音已经归了活动，那个去向照样在。开关只决定入口摆不摆出来。

## 一屏一个主要动作

- **首页**：一个「开始录音」。按钮下面第一排是语言，每种一颗胶囊，× 去掉、
  ＋ 加，末尾是「导入」；第二排是声音、主题、主持活动，每颗胶囊上写着当前的
  值（出字不在这里选，见上；出不了字时声音后面才多一样）；主持时多出第三排，
  放活动。没有「更改」，也没有说明句。再下面是录过的东西，按日期排。「开始录音」
  不再是单独的一页。
- **录音中**：文字占满。录音条上四样：标记、暂停、停止、⋯。
- **停止以后**：落在这场录音的页面上，顶上一张卡：一行「录好了 · 多长」，一排
  胶囊——复制（唯一的主按钮）、导出、分享、精修——和档案馆的状态。在主持的人，
  「分享」后面多一颗「交到活动」，还没归过活动的录音从这里交；归过的，点档案馆
  的状态，打开的是同一张表。复制的是眼前这一版。正在写这场录音笔记的人不被带走，只出一句提示；卡在他回到文字稿时还在。

## 界面怎么写

0.8.2 把东西分了层，却在每一层上都铺了说明句，常用的设置又收在一个不起眼的
「更改」后面。负责人用过以后的原话：「选语言应该在录音这里，可以直接配置，
不需要点击收起。」「下浮的更改，应该巧妙设计，得体设计，不然不容易发现。」
「有很多多余的解释性文字，你把你的用词一个词表达的清晰，不要有任何解释性
文字，看的很累。」这一节是由此定下的写法，适用于每一处界面。

1. **一个控件一个词。** 名字是名词或动词，不带解释；当前的值直接写在控件上。
   「麦克风」「出字」「主题」「主持活动」「导入」，不是「声音来源 — 录麦克风
   收到的声音…」。
2. **表面不写句子。** 页面、卡片、设置行上不放说明句。一行就是名字加控件。
   只有四种整句可以出现：空状态的那一句；出错时的那一句和它唯一的动作；
   确认框（不可逆的、对外的动作）；状态（「正在录音 · 文字慢了一点」）。
3. **说明进提示。** 想多说一句的，放工具提示和无障碍提示。必须让人读到的
   告知——东西会离开这台 Mac、交上去删不掉——放在动作发生那一刻的确认框里，
   或者控件旁边的 ⓘ 里，不铺在页面上。告知只挪位置，不删。
4. **设置直接可改。** 常用的摆在动作旁边、原地改。不用「更改」「展开」这种
   文字链接当入口；要收起的，入口自己得长得像控件：一颗写着当前值的胶囊。
5. **一种控件一个样子。** 胶囊是小控件的统一样子（`DesignSystem` 里的 Pill
   一族）：点一下就切换的开关胶囊、带 ⌄ 的菜单胶囊、只做一件事的动作胶囊。
   每屏只有一个主按钮。
6. **分组靠留白和一个词的小标题。** 不拿边框套边框，不给小标题配副标题。
7. **状态用图标加一个词。**「已交」「排队」「没交上」；细节点开再看。

写新界面之前先数一遍：除了标题和控件上的词，这一屏还剩几个句子。有，就先想
能不能去掉。

## 状态只说一处、一句

录音中文字正不正常，只在录音条计时旁边说一句；要人动手的时候，顶栏下面那一条
横幅给出原因和唯一的动作。别处不再重复。

先说录音有没有受影响，再说文字怎么了。不报秒数。

| 情况 | 那一句（简体 / English） |
| --- | --- |
| 一切正常 | 正在录音 / Recording |
| 这一场只录音 | 正在录音 · 只录音 / Recording · audio only |
| 文字还在接通 | 正在录音 · 正在接通文字 / Recording · connecting text |
| 文字落后 | 正在录音 · 文字慢了一点 / Recording · text is a little behind |
| 一部分语言停了 | 正在录音 · 部分文字停了 / Recording · some text stopped |
| 文字全停了 | 正在录音 · 文字停了 / Recording · text stopped |
| 没联网 | 正在录音 · 没联网，暂时出不了字 / Recording · offline, no text for now |
| 暂停、保存中 | 沿用原来的说法 |

## 主题是可选的

人只需要认识「录音」。录音默认按日期排；主题是给一个系列归类用的文件夹，
建了第一个，侧栏才出现「主题」。存储不变：没放进主题的录音仍在那个系统主题
里，界面上不再提它，也不再出现「未归入主题」这几个字——没放的录音就是录音。

一场录音的页面上不放「下一场录音」的默认值。默认值只在两处：首页的「更改」，
和主题自己的选项。

## 设置三节

- **账号**：四组，各一个词——身份（登录 Zu 的身份，现在就是城的扫码登录）、
  出字（邀请码，或自己的密钥）、设备、档案馆。
- **通用**：界面语言、外观、更新、快捷键。
- **高级**：自己的 Soniox 密钥、整理用的模型密钥、分享、备份、诊断信息。
  大多数人用不到。

登录以后转录由谁出钱，要等身份体系和服务端定下来。在那之前不登录也能用，
邀请码和自己的密钥照旧。

## 用词

一件事一个名字。下面是界面上唯一允许的说法；左栏的旧说法出现在界面上算缺陷。

| 旧说法 | 简体 | English |
| --- | --- | --- |
| 转录稿、转录、转写稿 | 文字稿 | transcript |
| 精修转录、精修版、音频转录、转录这段音频、录音后处理、停止后处理 | 精修（动作）· 精修稿（结果） | refine · refined transcript |
| 实时版、实时转录、边录边出的那一版（指那一版稿子） | 现场稿 | live version |
| 实时字幕（指开关） | 边录边出字 | live text |
| 实时字幕、悬浮字幕（指那个窗口） | 字幕窗 | caption window |
| 共享字幕、直播（指给会场的人看） | 给观众看字幕 | show captions to the audience |
| 现场说 / 只看字幕 | 说的语言 / 另外译成 | spoken languages / also translate into |
| 系统声音 | 电脑里的声音 | sound from this Mac |
| 全部录音 | 录音 | recordings |
| 未归入主题、首页快速录音 | （不出现） | — |
| 废纸篓 | 回收站 | trash |
| 共享（指发给别人看） | 分享 | share |
| 共享（指一起改主题笔记） | 协作 | collaborate |
| 主题设置 | 主题选项 | topic options |
| 密钥（不带名字） | Soniox 密钥、DeepSeek 密钥 | Soniox key, DeepSeek key |

「活动」只指城里的活动。字幕窗的两种排法叫「最新一句」和「对照」（那个切换
只有 144 pt 宽，各语言都用短词）。

供应商名（Soniox、DeepSeek）只出现在三种地方：「设置 › 高级」；首次使用里选
「用自己的密钥」的那一步；以及告诉人音频会发到哪里的那几句——那是告知，不能
为了用词干净把名字去掉。录音中的状态、提示和报错只说文字怎么了。

## 还没做的

- 「整理成纪要」：新功能，没定做不做。
- 登录以后转录由城提供：要服务端认身份。
- 设备、协作跟着身份走：要改同步那一层。
- 说话人的显示没有动。
- 回收站显示不了「什么时候删的」：核心没有这个时间。
- 没人引用的旧字符串没有清干净。
