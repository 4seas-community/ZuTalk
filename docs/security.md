# 安全说明

## 用户内容

音频、转录和笔记默认保存在本机。只有用户主动发起远程转录时，相关内容才会
发送给所选服务提供商。

## 服务凭据

服务凭据保存在应用私有目录的 `Secrets/provider-credentials.json` 中，只允许
当前 macOS 登录账户读取。凭据不会写入源码、日志、诊断信息、命令行参数、
UserDefaults、SQLite 或 macOS Keychain。

应用启动时会从该文件加载服务凭据，并在用户清除凭据时更新或删除对应记录。
存储实现使用受限的目录和文件权限、进程锁、临时文件与原子替换，避免其他
本机账户读取以及并发写入造成损坏。

## 发布凭据

Git 提交签名、Sparkle 更新签名和服务凭据彼此独立。任何私钥或服务密钥都不得
提交到仓库或包含在公开发布物中。
