# Zulangue Design System

Zulangue 的界面应当克制、清晰，并让录音、转录和保存状态容易确认。

## 核心原则

1. 使用统一的细边框和清晰的层级。
2. 间距优先使用 `4、8、12、16、24、32、48`。
3. 品牌绿色用于主操作、选择、焦点和导航状态。
4. 橙色仅用于录音或处理中的活动状态。
5. 红色仅用于破坏性操作和错误。
6. 深浅模式都应保持足够的文字与控件对比度。

## 颜色

颜色必须通过 `DesignSystem/Tokens.swift` 的语义 token 使用。视图不应直接
复制品牌色值，也不应根据具体页面创建新的同义 token。

## 排版

标题使用圆润的几何风格，正文使用系统字体。正文、说明、标签和数值应使用
明确的语义层级，不依赖任意字号组合。

## 组件

- 主按钮用于页面的主要动作。
- 次要按钮使用描边或低强调样式。
- Tab、焦点环和选中项使用品牌强调色。
- 录音指示器使用活动状态色。
- 错误和删除动作使用破坏性色。

## 可访问性

- 所有交互元素必须有稳定的辅助功能标签或标识。
- 键盘焦点必须可见。
- 动画应尊重系统的减少动态效果设置。
- 颜色不能作为传达状态的唯一方式。

## 验证

设计 token、组件状态和主界面品牌呈现应由 Swift 测试覆盖。界面改动完成后
运行 `just swift-test`。
