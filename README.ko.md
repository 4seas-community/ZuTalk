# Zulangue

[ไทย](README.th.md) | [English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [Deutsch](README.de.md) | **한국어** | [日本語](README.ja.md) | [简体中文](README.zh-Hans.md)

Zulangue는 음성을 녹음하고 전사하며 정리할 수 있도록 돕는 네이티브 macOS 음성 노트 앱입니다. 다국어 대화를 따라가는 플로팅 자막도 제공합니다.

## 다운로드

[최신 Zulangue 다운로드](https://github.com/4seas-community/zulangue/releases/latest)

Apple Silicon 및 Intel Mac을 지원하며 macOS 15.5 이상이 필요합니다.

설치 프로그램은 아직 Apple의 공증을 받지 않았습니다. macOS가 첫 실행을 차단하면 Finder에서 Zulangue를 Control-클릭한 뒤 “열기”를 선택하거나, 시스템 설정 → 개인정보 보호 및 보안에서 실행을 허용하세요.

## 주요 기능

- 오디오를 녹음하거나 가져와 Soniox로 전사
- 이동 및 크기 조절이 가능한 플로팅 창에서 다국어 실시간 자막 표시
- 녹음, 전사문, 메모를 Notebook으로 정리
- 콘텐츠 편집, 검색, 내보내기
- 앱 내 업데이트를 통해 새 버전 받기

## 개인정보 보호

오디오, 전사문, 메모는 기본적으로 사용자의 Mac에 보관됩니다. 원격 전사를 직접 사용할 때만 콘텐츠가 서비스 제공업체로 전송됩니다. API 자격 증명은 로컬에 저장되며 저장소에 커밋되지 않습니다.
