# ZuTalk 0.5.6

Notes look like writing again, not like an outline.

ZuTalk requires macOS 12.5 or later.

- **A paragraph no longer gets a bullet.** Every line used to be given a
  dot, so a page of ordinary notes read as a dismantled outline. Plain
  lines are now plain, and they start at the left margin instead of behind
  an empty marker slot.

- **Bullets come from asking for one.** Type `- ` for a list item, `- [ ] `
  for a checkbox. An empty list line leaves the list on Return.

- **Empty lines are empty.** They kept their height but no longer show a
  naked dot.

- **Indentation carries the hierarchy** instead of switching the dot to a
  hollow circle one level in.

- **More air between paragraphs.** The old spacing was tight enough that
  the bullets were doing the work of separating lines.

Existing notes keep every character and their indentation; lines saved
before this version simply stop showing a dot.
