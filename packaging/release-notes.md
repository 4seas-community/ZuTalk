# ZuTalk 0.8.4

Recording gives you text without being asked, and a finished recording can
be filed to a city event from where it is.

ZuTalk requires macOS 12.5 or later.

## Live text is no longer a switch

- **Recording produces live text whenever it can.** The Live text switch is
  gone from Home and from a topic's Start Recording. With an invite code or
  your own key, pressing Start gives you text; there is nothing to turn on.
  If you had chosen audio only in an earlier version, recordings get live
  text again.
- **If nothing is set up, Home says so.** A dimmed Live text pill with a
  warning mark opens Settings › Account, where the invite code goes.
  Without a network, a quiet "offline" status takes its place.
- **Offline with an invite code no longer blocks recording.** Starting used
  to fail and ask you to turn live text off. The recording now starts as
  audio only and says so.
- **To record audio only,** switch the invite code off in Settings ›
  Account, as before.
- That audio is sent to Soniox to be written and translated is still
  stated: in the Start button's tooltip, and behind the ⓘ beside Live text
  in Settings › Account.

## Filing a finished recording to an event

- **File to event.** A recording that was not given an event when it
  started can now be filed afterwards from the recording itself: on the
  card after Stop, on the recording's tab bar, and in its ⋯ menu on its
  page, on Home and inside a topic. It opens the archive panel for that
  recording: choose the event, file, add or withhold the audio, open it in
  the city, withdraw.
- The pill on the card and the tab bar appears when you are signed in to a
  city and Hosting is on; the menu item appears whenever you are signed in.
  Once a recording has an event, the same place shows its status, and a
  click opens the same panel.
- What is filed is public and stays in the city's records, text and audio
  alike; the panel says so behind its ⓘ.

Nothing in this version was clicked through in a running app before
release; it was checked with tests and rendered screens. The new wording
in languages other than Chinese and English was written by a model.
