# ZuTalk 0.5.7

The notes tab is a page you write on.

ZuTalk requires macOS 12.5 or later.

- **Text sits in a centred column** instead of running from the left edge
  across the whole window. Long lines are easier to read back, and a wide
  window no longer looks half empty. Clicking beside the column still puts
  the cursor in the text.

- **Bigger type, more room between lines.** The body was set at a size
  meant for lists and inspectors; it is now sized for writing.

- **Tab indents properly.** One press is one action — one undo, not one
  per line. Indenting a line carries its sub-items with it, the selection
  survives, and a move the outline cannot make says so instead of doing
  nothing silently.

- **Less in the way.** The explanatory strip above the editor is gone, and
  the undo/indent buttons stay faint until you move the pointer into the
  page.
